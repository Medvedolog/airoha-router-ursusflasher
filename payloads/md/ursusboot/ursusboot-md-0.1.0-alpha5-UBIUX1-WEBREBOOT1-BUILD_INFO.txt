Baseline source: UrsusBoot 0.1.0-alpha5-UBIUX1
Scope: WebFailsafe manual reboot lifecycle only

Behavior change:
- POST /api/reboot still requires a completed flash operation and X-Ursus-Confirm: REBOOT.
- Automatic reboot after firmware write is NOT enabled.
- The REBOOTING HTTP response is queued first.
- Once the complete response has been queued, a 500 ms grace timer starts.
- WebFailsafe exits and invokes the existing U-Boot reset command after the grace period even if the browser does not ACK/close the TCP connection.
- Existing ACK-driven stop_after_response remains intact as the fast path.
- boot-once, stock-layout install, UBI writers, FIP writer, NAND/Fudan code and OpenWrt payloads are unchanged.
