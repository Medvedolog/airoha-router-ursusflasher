# Патчи для репозитория airoha-ursusboot

Здесь лежали патчи для
[Medvedolog/airoha-ursusboot](https://github.com/Medvedolog/airoha-ursusboot),
потому что в тот репозиторий нет доступа на запись.

## Открытых патчей нет

Всё вмерджено или заменено более удачным решением на стороне репозитория:

| Патч | Судьба |
|---|---|
| data-driven `build.sh`, упаковка FIP, QA-стражи, README | вмерджен в `43fca746` |
| `borrowed`-фикс в `cmd/lwip/ping.c` | вмерджен, сторожится `qa.sh` |
| `CONFIG_ENV_OVERWRITE=y` для MF + раздел «Recovery MAC identity» | вмерджен в `e5ae5747` |
| `docs/HW_TEST_MAC.md` (A/B/C MAC-тест) | **не нужен**: покрыт `docs/TESTING.md` в `b8164653` |

Последний случай стоит пояснить. Отдельный файл под MAC-тест был промежуточным
решением, потому что тест существовал только в переписке. В `b8164653` он вошёл
в `docs/TESTING.md` как часть общей трёхуровневой модели доказательств
(QA PASS / Build PASS / HW PASS) вместе с проверками WebFailsafe, UART
stop/restart и прошивки. Это лучше отдельного файла: у оператора один документ
приёмки, а не два пересекающихся. Уникальная часть моей версии — проверка
согласованности env и MAC-фильтра контроллера — сохранена там как
«Controller/env consistency check».

Если снова понадобится что-то передать в тот репозиторий — класть сюда.
