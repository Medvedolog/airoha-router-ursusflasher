## Назначение

**UrsusFlasher** — утилита для ПК, которая определяет текущее состояние Nokia XG-040G-MD и выбирает подходящий способ установки, обновления, резервного копирования или аварийного восстановления.

**UrsusBoot** — загрузчик на базе U-Boot со встроенной средой восстановления WebFailsafe. Он используется как промежуточная безопасная среда для проверки образов, записи OpenWrt и обслуживания загрузчика.

Текущий комплект:

```text
UrsusFlasher  0.2.51-md-alpha4-fudan1-stateui5-payloadrefresh1-rootfsmax2
UrsusBoot     0.1.0-alpha4-FUDAN1
Устройство    Nokia XG-040G-MD / Airoha AN7581 / 256 MiB SPI-NAND
OpenWrt       r36009+75-6c315233aa / Linux 6.18.44
Проверка      PASS
FUDAN1        HW_TEST_REQUIRED
```

Интернет для обычной прошивки не требуется: рабочие образы и служебные компоненты входят в комплект.

## Быстрый запуск

### Windows

```text
START_ONECLICK.cmd
```

Для ручных операций:

```text
START_EXPERT.cmd
```

### Linux / macOS

```bash
./START_ONECLICK.sh
```

Для ручных операций:

```bash
./START_EXPERT.sh
```

**ONE-CLICK** — основной автоматический сценарий. Он сам определяет, что сейчас запущено на роутере, проверяет необходимые файлы и выбирает рабочий путь.

**EXPERT** — меню для установки и обслуживания загрузчика, аварийного восстановления, резервного копирования и диагностики.

## Как подключать Ethernet

**Для прошивки рекомендуется использовать порты LAN2 или LAN3.**

- **LAN1** — отдельный порт 2,5 Гбит/с на PHY Airoha EN8811H. Для этого PHY применяются отдельные исправления инициализации, поэтому для переходов между прошивками и аварийных процедур LAN1 не используется как основной порт.
- **LAN4** в комплектной сборке OpenWrt от 06.09.2026 после загрузки назначается **WAN**. Если ПК подключён к LAN4, после первой загрузки OpenWrt доступ к `192.168.1.1` может пропасть.
- Для непрерывного доступа от начала прошивки до первой загрузки OpenWrt используйте **LAN2 или LAN3**.

## Как работает ONE-CLICK

ONE-CLICK не привязан к одному исходному состоянию. Он сначала определяет устройство и только затем выбирает маршрут.

### Если запущена заводская прошивка Nokia

```text
HTTP/Web Nokia
  -> определение модели и получение штатных данных доступа
  -> root-сеанс Telnet
  -> полная резервная копия mtd0..mtd16 через TFTP
  -> проверка резервной копии
  -> подготовка нового mtd0 с сохранением ROM prefix и tcboot env
  -> запись UrsusBoot FUDAN1 в mtd0
  -> полное обратное чтение mtd0 и сверка SHA256
  -> перезагрузка в UrsusBoot Recovery
  -> проверка и запись OpenWrt через WebFailsafe API
  -> обратное чтение и проверка результата
```

Запись загрузчика не начинается, пока полная копия заводской flash-памяти не пройдёт проверку.

### Если уже запущена OpenWrt

```text
root SSH
  -> подтверждение платы и среды выполнения
  -> копирование UrsusBoot через SCP
  -> обновление UBI-тома fip, если он существует
     ИЛИ
     запись физического boot block только при однозначно подтверждённой цели
  -> полное обратное чтение и сверка SHA256
  -> переход в UrsusBoot Recovery
  -> проверка и обновление OpenWrt
```

OpenWrt, установленная во flash-памяти, и OpenWrt/initramfs, запущенная из RAM, распознаются отдельно. Транспорт в обоих случаях — root SSH, но среда выполнения отображается в интерфейсе.

### Если уже открыт UrsusBoot Recovery

```text
HTTP API UrsusBoot
  -> определение текущей разметки
  -> передача подходящего sysupgrade-образа
  -> проверка класса и размера образа
  -> запись только разрешённым для текущей разметки способом
  -> проверка записи
  -> перезагрузка
```

Повторная установка загрузчика в этом случае не требуется, если его версия и состояние уже подтверждены.

## Каналы управления и передачи файлов

| Состояние устройства | Управление | Передача данных | Для чего используется |
|---|---|---|---|
| Nokia STOCK | HTTP/Web + Telnet | TFTP | Определение устройства, root-доступ, полная копия flash, передача подготовленного `mtd0` |
| OpenWrt во flash-памяти | SSH | SCP | Установка/переустановка UrsusBoot, чтение текущего состояния, передача FIP или boot block |
| OpenWrt/initramfs в RAM | SSH | SCP | Те же операции с загрузчиком из среды, которая не исполняется с постоянного rootfs |
| UrsusBoot Recovery | HTTP API | HTTP по частям | Проверка состояния, передача OpenWrt/FIP/preloader, запуск операций записи и получение статуса |
| UrsusBoot Recovery, резервный способ | консоль UrsusBoot | TFTP | Запасной транспорт для передачи FIP, если передача через WebFailsafe не завершилась |
| Airoha BootROM | USB-UART 3,3 В | XMODEM, затем служебная RAM-среда | Аварийный запуск восстановления без использования установленной системы |

USB-UART подключается только по **TX/RX/GND**; VCC к плате роутера не подключается.

## Что проверяется перед записью

UrsusFlasher разделяет определение состояния, передачу файла и саму запись. Для операций, меняющих flash-память, используются несколько независимых проверок.

1. **Файлы комплекта** — размер, SHA256 и запись в манифесте.
2. **Устройство** — модель, SoC, доступный интерфейс управления, загрузчик и текущая разметка.
3. **Среда OpenWrt** — установленная система во flash-памяти или root, запущенный из RAM.
4. **Цель записи** — конкретный MTD-раздел или UBI-том, его размер и состояние.
5. **Резервная копия** — для штатной установки с Nokia STOCK проверяется полный набор `mtd0..mtd16`, размеры и контрольные суммы.
6. **Переданный файл** — размер и хеш сверяются уже на стороне роутера до начала записи.

Если обязательные сведения определить не удалось, операции, способные выполнять запись во flash-память, остаются видимыми в EXPERT, но недоступны для запуска.

---

## Что проверяется после записи

Запись не считается завершённой только потому, что команда записи вернула код успеха.

- Для `mtd0` выполняется полное обратное чтение 512 КиБ и сравнение SHA256.
- Для UBI-тома `fip` выполняется обратное чтение всего записанного FIP и сравнение SHA256.
- В UrsusBoot Recovery запись OpenWrt сопровождается встроенной проверкой целевого объекта и чтением результата.
- После перезагрузки, когда это возможно, проверяется фактически ответившая среда: Nokia STOCK, UrsusBoot Recovery или OpenWrt.

При несовпадении после обратного чтения автоматическая повторная запись другим способом не запускается.

## Резервное копирование

### Nokia STOCK

Пункт **7 «Создать полную копию flash-памяти»** работает в режиме чтения.

Если штатный доступ уже существует, UrsusFlasher использует его без включения дополнительных служб ради копирования. Для полной копии сохраняются `mtd0..mtd16`, сведения о разметке и данные, необходимые для проверки принадлежности копии устройству.

### Если безопасное копирование из работающей системы невозможно

Используется путь **Airoha BootROM → среда в RAM**. Постоянная flash-память при запуске этой среды не изменяется; копирование выполняется из состояния, в котором рабочая система не меняет содержимое NAND во время чтения.

Копия, полученная из работающей записываемой OpenWrt, не выдаётся за точную копию для полного восстановления.

## Аварийное восстановление загрузчика

Пункт 5 используется, когда штатная система не загружается и доступ по сети отсутствует.

Основной путь:

```text
USB-UART 3,3 В
  -> Airoha BootROM
  -> передача служебных компонентов в RAM по XMODEM
  -> запуск среды восстановления из RAM
  -> проверка целевых объектов
  -> запись загрузочной цепочки
  -> полное обратное чтение и проверка
```

Подробная последовательность подключения UART и работы с Reset приведена в [`docs/EMERGENCY_URSUSBOOT_RU.md`](docs/EMERGENCY_URSUSBOOT_RU.md).
