# WEBREBOOT1 — аппаратный тест

Кандидат исправляет только ручную перезагрузку WebFailsafe. Автоматическая перезагрузка после успешной записи OpenWrt не добавляется.

## Проверка

1. Загрузить/установить `ursusboot-md-0.1.0-alpha5-UBIUX1-WEBREBOOT1-update.fip` штатным способом обновления UrsusBoot.
2. Войти в Recovery и убедиться, что версия отображается как `0.1.0-alpha5-UBIUX1-WEBREBOOT1`.
3. Выполнить штатную операцию записи, после которой Web UI разрешает ручную перезагрузку.
4. Нажать кнопку перезагрузки и подтвердить её.
5. Ожидаемый UART-маркер до reset:
   `URSUS_WEBREBOOT_RESPONSE_QUEUED grace_ms=500`
6. Если браузер не закрывает/не ACK-ает соединение, спустя grace period ожидается:
   `URSUS_WEBREBOOT_GRACE_EXPIRED action=reset`
7. Затем должен появиться существующий маркер:
   `URSUS_UBI_MIGRATION_OPERATOR_REBOOT`
   и устройство должно выполнить обычный hardware reset.

## Критерии PASS

- кнопка reboot работает при обычном браузерном сценарии;
- reboot работает даже при удерживаемом HTTP/TCP соединении;
- до нажатия кнопки самопроизвольного reboot после успешной прошивки нет;
- ошибка/незавершённая flash operation не разрешает `/api/reboot`;
- после reset устройство загружается штатно, без регрессии NAND/UBI.
