# 🐻🌲 Медведь научился разговаривать: живая консоль UrsusBoot 🌲🐻

> 🍯 **UrsusFlasher · BEAR METAL TOOL** — пункт **14** в EXPERT.
> 🌲🌲🌲 Один медведь, один роутер, ни одного паяльника.

---

## 🍄 Что это

Поднимаешь UrsusBoot, тыкаешь в пункт **14** — и у тебя в лапах настоящая консоль U-Boot прямо в окне флешера. Без провода на плату, без танцев с бубном вокруг COM-порта. Медведь рычит по сети, ты слушаешь. 🐾

## 🌰 Зачем это всё

Раньше, чтобы снять дамп или закинуть файл в роутер, приходилось выманивать медведя из берлоги: UART, XMODEM, TFTP-сервер на ПК, дырка в файрволе. 🦌🪵 Теперь берлога сама открывает дверь:

- 🌿 вводишь команды U-Boot как за UART;
- 🌲 закидываешь файлы в оперативку роутера;
- 🍯 снимаешь и заливаешь NAND без лишних лесорубов.

---

## 🍁 Клавиши прямо в консоли

| 🌲 Клавиша | 🐻 Что делает |
|---|---|
| **F2** ⬆️ | Закинуть в RAM: initramfs, прошивку OpenWrt, FIP UrsusBoot, Vanilla FIP, UBI preloader или любой файл по XMODEM. Флеш не трогается 🍃 |
| **F3** ⬇️ | Достать: диагностику UrsusBoot по HTTP или диапазон RAM через TFTP PUT 🦔 |
| **F4** 🔀 | Переключить «строки» / «RAW» |
| **F5** 💾 | NAND-пресеты (ниже) 🌰 |
| **F10** 🚪 | Выйти из берлоги |

## 🍯 F5: пресеты NAND

1. 🌲 **Снять весь NAND**
2. 🌿 **Снять один раздел**
3. 🍄 **Залить раздел из архива**
4. 🪵 **Залить весь NAND из архива**

### 🦉 Как снимается (UrsusBoot **T77** и новее)

Бэкап идёт **одним потоком по HTTP**: роутер читает флеш и отдаёт по мере отправки.

- 🍃 нет промежуточных буферов в RAM;
- 🌲 не нужен TFTP-сервер на ПК и дырка в файрволе;
- 🐾 плохие блоки лежат в архиве как `0xFF`, физические смещения сохраняются;
- 🦌 после обрыва можно **докачать** с места остановки;
- 🔍 хеши сверяются независимой выборкой прямо через U-Boot.

Заливка обратно идёт по **TFTP**. 🐿️

---

## ⚠️ Важная оговорка, медвежья

> 🐻 **Сетевая консоль работает, только когда медвежонок уже запущен.**
> То есть роутер стоит в **UrsusBoot Recovery** и отвечает на `192.168.1.1`. 🏠
> Если UrsusBoot не стартует, по сети говорить не с кем. 🦗

Для этого случая есть **UART-режим** 🔌🌲: в пункте 14 выбираешь «UART (COM-порт)» и получаешь тот же зелёный терминал, но по проводу.

- 🍃 115200 8N1, сеть не нужна;
- 🌰 работает с BootROM, U-Boot и UrsusBoot;
- 🪵 цена: **F2/F3/F5 там недоступны**, файлы и NAND ходят только по Ethernet.

Выбор делается в самом пункте 14: `1` — Ethernet (WebSocket), `2` — UART (COM), Enter = Ethernet. 🐾

---

## 🌲 Для комфорта зверя

- 🟢 тёмно-зелёная берлога вместо унылого серого окна;
- ⬆️⬇️ **Вверх/Вниз** листают историю команд (у оболочки роутера её нет, историю ведёт флешер);
- ⌫ Backspace стирает, а не рисует `\b \b`;
- 🖥️ окно можно растянуть на весь экран, панель подстроится;
- 🎨 запросы после F2/F3/F5 оформлены цветом, как остальные меню.

---

## 🦫 Осторожно, медведь кусается

- 🔥 **Ctrl-C на пустом приглашении** останавливает весь WebFailsafe вместе с консолью. Флешер спросит второй раз, только потом отправит. Выходить лучше через **F10**. 🚪
- 🪓 Команды записи в консоли **не фильтруются**. Хочешь стереть флеш, медведь стирает. Ответственность на лапе оператора.
- 🧪 Это **dev-сборка**: потоковый бэкап, докачка, UART-режим и цвета ещё **не прогонялись на железе целиком** (HW PENDING). Для обновления и восстановления UrsusBoot по UART есть отдельные пункты меню.

## 🍄 Какая прошивка нужна

| 🐻 Версия | 🌲 Что даёт |
|---|---|
| **T77** | потоковый бэкап и каталог NAND |
| **T78** | Backspace без каракуль |
| **T79** | роутер сам отпускает зависшую консольную сессию: без этого после «вырванной» вкладки можно получить 409 «консоль занята», а в `help` нет версии в каждой строке |

> 🍯 Комплект UrsusFlasher выравнивается с прошивкой по номеру: **0.2.77 ↔ T77**, и так далее. Версия **0.2.79** соберётся, когда доедет T79.
